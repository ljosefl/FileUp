# FileUp

Настольное приложение **Windows** для переноса данных из **Microsoft Excel** в **Microsoft SQL Server** без написания SQL вручную.

## Возможности

- **Подключение к SQL Server** — выбор сервера и ODBC-драйвера, **проверка подключения** к `master` и список баз.
- **Аутентификация** — **Windows (Trusted Connection)** или **логин и пароль** SQL Server.
- **Выбор цели** — база данных из списка, **схема** (по умолчанию `dbo`), таблица из списка существующих **или** ввод `схема.имя` вручную. Кнопка **обновления** списка таблиц.
- **Создание таблицы из интерфейса** — отдельное окно: имя таблицы, схема, при необходимости столбец **Id** `BIGINT IDENTITY(1,1) PRIMARY KEY`, список **столбцов** с выбором **типа SQL Server** (числа, строки, даты, `UNIQUEIDENTIFIER` и т.д.) и флага **NULL** / **NOT NULL**.
- **Загрузка Excel** — выбор файла (`.xlsx`, `.xls`), автоматический список **листов**, чтение выбранного листа через **pandas**.
- **Режим записи** — **`replace`** (пересоздать содержимое через `pandas.to_sql`) или **`append`** (дописать строки).
- **Журнал** — текстовый лог действий и ошибок в нижней части окна.
- **Размер окна** — главное окно можно **растягивать**; блок журнала расширяется вместе с окном.

Подробности по выпускам и номерам версий — в файле [`VERSIONS.md`](VERSIONS.md).

## Требования

На компьютере установлен [**ODBC Driver for SQL Server**](https://learn.microsoft.com/sql/connect/odbc/download-odbc-driver-for-sql-server) (обычно **17** или **18**).

## Сборка exe (Windows)

```text
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
pyinstaller app.spec
```

Готовый файл: `dist\FileUp.exe`.
