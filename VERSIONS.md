# Версии FileUp

Нумерация после предрелиза **0.9**: далее **1.0**, **1.1**, **1.2**, … (не 0.10).

| Версия | Дата       | Изменения |
|--------|------------|-----------|
| **1.2** | 2026-04-24 | Кнопка «Проверить обновления» в футере; резервный запрос списка релизов GitHub, если недоступен `/releases/latest`. README переписан под возможности приложения. |
| **1.1** | 2026-04-24 | Диалог «Новая таблица»: корректный родитель окна (`tk.Toplevel`), исправление `pack(fill=…)` (используется `X`, не `EW`). Область столбцов — Canvas + `tk.Frame`. Главное окно явно `resizable(True, True)`. |
| **1.0** | 2026-04-23 | Первый стабильный релиз после 0.9. Исправлен запуск: импорт константы `E` для `sticky` в футере (`NameError`). Интерфейс на ttkbootstrap, бренд **FileUp**, футер с версией, создание таблиц SQL Server из UI с выбором типов колонок, проверка обновлений через GitHub Releases, сборка `FileUp.exe`. |
| **0.9** | —          | Предрелиз: загрузка Excel → SQL Server, подключение ODBC, режимы replace/append. |
